# Юридика и платежи для RF-фаундеров B2B-сервисов (2026)

Research agent report, 2026-07-22. Позиция: только прозрачные декларируемые пути; сокрытие RF-резидентства от KYC = ToS-фрод и риск circumvention.

## 1. RF-домашний путь

Самозанятость (НПД): 4%/6% (юрлица, включая иностранные - 6%), кэп 2.4M ₽/год (~$30K), заморожено до 2028. Маркетинг/консалтинг - можно; агентская перепродажа - нельзя. Иностранные клиенты: легально и просто - валютный контроль НЕ применяется (нет ИП = нет ВЭД-бумаг), деньги на личный счёт, чек в «Мой налог» в рублях по курсу ЦБ на дату получения; договор+инвойсы для тишины 115-ФЗ. Сетап: бесплатно, 10 минут.

ИП УСН 6%: взносы 57,390 ₽/2026 + 1% свыше 300K (вычитается). Валюта: полный валютный контроль (173-ФЗ, 181-И), контракт >600K ₽ на учёт. SWIFT-реальность: узкий пул банков, дни-30 рабочих дней, ~$200 комиссий, sender-side отказы часты. Штрафы за валютные нарушения до 75-100% транзакции.

Вердикт: RF-клиенты = самозанятость на старт, ИП УСН 6% после 2.4M или по требованию клиентов.

## 2. Иностранные юрлица

Консенсус практиков: ~90% RF-фрилансеров не заводят иностранное ИП вообще - платформы + RF-статус закрывают; иностранное юрлицо окупается только на реальной выручке или по требованию клиента/рейла.

- Армения ИП: удалённо можно (POA), налог 10% (повышен с 5%), сетап $300-600, но банки теперь хотят ВНЖ/трудовой+аренду.
- Грузия ИП: 1% до 500K GEL, но банки ВНЖ-gated (Credo - главная дверь), правила ужесточаются.
- Кыргызстан: 2-6%, удалённо больше нельзя, KICB ограничил RF-клиентов (фев 2026).
- Казахстан: нужен РПП (резидентство), карты нерезидентам кэп 12 мес.
- UAE freezone/freelance: $2,500-6,000 год 1, ~$2,000-4,500/год далее, личное присутствие для визы/Emirates ID/банка; лимитированный Stripe; новый СОИДН РФ-ОАЭ с 01.01.2026.

КИК: иностранное ИП ≠ КИК; иностранное LLC = КИК (уведомления, штраф 500K ₽) → только ИП-форма пока RF-резидент. RF-резидент платит НДФЛ 13-22% на мировой доход; спецрежимные налоги (армянские 10%, грузинский 1%) НЕ зачитываются по СОИДН → двойная нагрузка. "1% Грузия" для RF-резидента - мираж. Иностранный счёт: уведомление ФНС 30 дней + отчёт о движении до 1 июня.

## 3. Платёжные рейлы

- Stripe: запрещён для находящихся/резидентов РФ (и Atlas). Только через юрлицо в поддерживаемой стране (UAE limited; Армения/Грузия/КЗ/КГ - не поддерживаются).
- PayPal: закрыт с 2022, возврата нет.
- Wise/Payoneer: только с реальным ВНЖ/ПМЖ + address proof; открытие на иностранное ИП при жизни в РФ = закрытие на re-KYC. Не врать о резидентстве.
- Deel: РФ в restricted, RICO-иск за legacy RF - не строить на нём. Работает для подрядчиков в АМ/ГЕ/КЗ/КГ/UAE при реальной релокации.
- **Mellow / EasyStaff (workhorse)**: Mellow (экс-Solar Staff foreign arm, сплит июнь 2024) инвойсит западного клиента от своего не-RF юрлица и платит тебе в РФ как самозанятому/ИП/физлицу. Комиссии: Mellow от 5% (bank) / 8% (card); EasyStaff 6% + payout fee.
- SWIFT в RF-банк: легально, ненадёжно.
- Крипта (USDT): финальное голосование по рамочному закону 21-22 июля 2026. Внутренние платежи в крипте запрещены (штрафы от 100K ₽) - RF-клиенту в USDT инвойсить нельзя. Трансграничные расчёты разрешены без ограничений (продолжение ЭПР 2024), BTC/ETH/USDT auto-qualify, физлица через иностранные кастодиальные кошельки. Налог: НДФЛ 13% до 2.4M/15% выше, 3-НДФЛ, каждая конвертация = налоговое событие, НПД к крипте неприменим. EU-клиент, платящий RF-резиденту в USDT, сам в серо-красной зоне (Art. 5b(2)) - крипта для не-EU клиентов.

## 4. Клиентская сторона

- Легальность: покупка маркетинг-услуг у RF-физлица НЕ запрещена для US/EU компаний (EC FAQ: платежи за незапрещённую торговлю разрешены).
- Реальность: банковский de-risking тотален; 19-й (ноя 2025) и 20-й (апр-май 2026) пакеты делают комплаенс пугливее. SMB/стартапы сильно спокойнее энтерпрайза.
- Комфорт procurement по возрастанию цены: (1) контракт с платформенным юрлицом (Mellow/EasyStaff) - самый дешёвый де-фрикшн; (2) АМ/КГ/КЗ ИП - ок для SMB; (3) UAE юрлицо+банк - "чистый" ответ для энтерпрайза + единственный реальный Stripe; (4) релоцированный кофаундер - структурный фикс: не-RF фаундер держит юрлицо/счета/Stripe, RF-фаундер = disclosed-подрядчик.
- Не искажать место выполнения работ и владение юрлицом.

## 5. Матрица рекомендаций

Phase 1 (валидация, $0):
- RF-клиенты: самозанятость у обоих, каждый инвойсит свою долю. 0 ₽, 10 мин, 6%.
- Global: самозанятость + Mellow/EasyStaff (клиент платит карте/wire платформенному юрлицу, ты получаешь ₽, чек НПД). Бэкап: USDT для крипто-комфортных не-EU клиентов через 3-НДФЛ. Итоговое трение ~11-14% выручки.
- Оба: те же два рейла параллельно.

Phase 2 (>~200K ₽/мес или >2.4M ₽/год, или enterprise):
- RF: ИП УСН 6%.
- Global fork: (i) платформенные рейлы на ИП УСН (простейшее, полностью RF-declared); (ii) релокация одного фаундера → Армения ИП (~$500-1,000) + Wise/Payoneer на реальном резидентстве; (iii) UAE ($2,500-6,000) для Stripe + enterprise-optics + СОИДН. Для RF-резидента (ii)/(iii) всё равно несут RF НДФЛ с неполными зачётами - считать total tax до выбора.

## Takeaways

1. Стартовать за $0 легально сегодня: самозанятость + Mellow/EasyStaff. Трение ~11-14%.
2. Кэп НПД 2.4M ₽ на фаундера = метр Phase-1 (~$60K/год на двоих).
3. Stripe/PayPal/Wise/Payoneer/Deel закрыты RF-резидентам, точка. Фейк резидентства = потеря счёта + fraud exposure.
4. Иностранное ИП ≠ КИК, LLC = КИК. Только ИП-форма.
5. "1% Грузия / 4% Кыргызстан" для RF-резидента - мираж (двойной налог + de-risking банков).
6. Крипта - юридически чистейший трансграничный рейл с RF-стороны (закон июля 2026), но НДФЛ 13/15%, запрет внутри РФ, и не для EU-клиентов.
7. Продавать услуги из РФ не санкционировано; проблема - получить деньги. Структурировать так, чтобы деньги клиента не касались российского банка напрямую.
8. Максимальный структурный рычаг = релокация одного фаундера (Anna?). Всё остальное - обходные пути вокруг этого решения.
9. UAE = ответ для enterprise, не для бутстрапа.
10. Всё ужесточается; строить на декларируемых скучных структурах, держать второй рейл тёплым.

## Чеклисты "до первого инвойса"

RF-only: оба регистрируют НПД; сплит выручки через раздельные инвойсы; шаблон договор+акт; чек на каждое поступление; календарь-чек на 1.8M ₽.

Global-only: НПД; онбординг на Mellow И EasyStaff (редундантность), тест $50-100; клаузы в договоры (услуги named individuals, инвойс через платформу, цены USD/EUR с заложенными 5-8%); для крипто-клиентов - кошелёк + иностранный кастодиальный аккаунт + план офф-рампа + 3-НДФЛ; НЕ открывать Wise/Stripe на чужой адрес; честно отвечать на комплаенс-анкеты.

Оба: раздельные договоры и учёт с первого дня; при >150-200K ₽/мес - ИП УСН для RF-потока; при стабильных >$2-3K/мес foreign - развилка Phase 2 с моделированием total tax; иностранный счёт = уведомление ФНС + отчёт 1 июня + только ИП-форма; ре-проверка платформ/банков ежеквартально.
